# CW Timeout Fix

## What was wrong
- The invalid CW evaluation file contained only:
  - `"error": "function_timeout"`
  - `"error": "function_error: Request timed out."`
- Those strings are not generated by the checked-in Creative Writing source, so the failing run was being terminated by an external timeout wrapper.
- Inside the repo, the CW pipeline still had a real timeout fragility:
  - `ChatOpenAI(...)` clients were created without explicit `request_timeout` or `max_retries`
  - CW evaluation and role/prompt paths used raw `chain.invoke(...)` calls without local retry handling

## Stage 1 Findings
- Exact-string search:
  - `grep -RInE "function_timeout|Request timed out" creative_writing || true`
  - Result: no matches in the checked-in `creative_writing/` source tree.
- Timeout-setting search:
  - `creative_writing/llm_utils.py:34`
  - `creative_writing/llm_utils.py:35`
  - `creative_writing/llm_utils.py:39`
  - `creative_writing/llm_utils.py:40`
- Where the error field is injected into `results.jsonl`:
  - [`creative_writing/test.py:44`](/Users/linruihe/Local%20Documents/Github/SwarmAgenticCode/creative_writing/test.py#L44)
  - [`creative_writing/test.py:49`](/Users/linruihe/Local%20Documents/Github/SwarmAgenticCode/creative_writing/test.py#L49)
  - This repo writes errors as `"{type(exc).__name__}: {exc}"`, not as `"function_timeout"`.
- Where LLM evaluation happens:
  - [`creative_writing/test.py:37`](/Users/linruihe/Local%20Documents/Github/SwarmAgenticCode/creative_writing/test.py#L37)
  - [`creative_writing/test.py:38`](/Users/linruihe/Local%20Documents/Github/SwarmAgenticCode/creative_writing/test.py#L38)
  - [`creative_writing/test.py:124`](/Users/linruihe/Local%20Documents/Github/SwarmAgenticCode/creative_writing/test.py#L124)
  - [`creative_writing/test.py:125`](/Users/linruihe/Local%20Documents/Github/SwarmAgenticCode/creative_writing/test.py#L125)
  - [`creative_writing/llm_utils.py:33`](/Users/linruihe/Local%20Documents/Github/SwarmAgenticCode/creative_writing/llm_utils.py#L33)
  - [`creative_writing/llm_utils.py:40`](/Users/linruihe/Local%20Documents/Github/SwarmAgenticCode/creative_writing/llm_utils.py#L40)
- Conclusion:
  - The historic `"function_timeout"` rows in `creative_writing/results_cw_main/test_95/results.jsonl` were injected outside the checked-in CW code.
